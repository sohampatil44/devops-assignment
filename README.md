# DevOps Assignment – Spring Boot Microservice

This project contains a simple **Spring Boot CRUD microservice** connected to a MySQL database using Docker Compose and CI/CD integration via GitHub Actions.

---

## 🔧 Tech Stack

- **Java 17**
- **Spring Boot**
- **MySQL**
- **Docker & Docker Compose**
- **GitHub Actions** (CI/CD)

---

## 🚀 Run Locally Using Docker Compose

### Prerequisites
- Docker Desktop installed

### Run Command
```bash
docker-compose up --build
